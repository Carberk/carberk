# Vehicle History

This context owns private customer enquiries and assignment authority. Customer create/list/detail check the current requester through identity's public session/read/check ports; they require neither staff grants nor TOTP. Assigned public identity comes through IdentityReadPort. Staff session/TOTP/lifecycle/exact-purpose authority remains identity-owned through StaffAccessPort. There are no orders, messages, wallet/provider calls or live intake.

Start with the [customer HTTP boundary and database tests](presentation/HistoryRequestsController.e2e.spec.ts) or the [staff desk](presentation/VehicleHistoryController.ts). Entry defaults off, requires explicit local synthetic tester admission, and always refuses staging/production. A requester-scoped attempt key preserves retries; a new request uses a new key. Source Listing IDs are immutable untrusted context, not foreign keys or authority; later Listing changes/deletion cannot rewrite the enquiry.

The [temporary operator HTTP boundary](presentation/HistoryAssignmentController.ts) exposes minimal unassigned/mine metadata and DB-arbitrated versioned claims. Only the current assignee can read selected context; uncertain same-owner retries do not increment the version again. The old desk response stays empty for its existing Admin consumer. Actual inbox, messaging, native assigned header/composer and handover remain separate delivery slices.
