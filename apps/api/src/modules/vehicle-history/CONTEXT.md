# Vehicle History

This context currently owns only the empty synthetic operator desk. Identity owns purpose grants/current-session checks through its public staff boundary; service object/assignment policy belongs here when requests exist. It has no customer intake, wallet/provider calls or onboarding endpoint.

Start with the [HTTP controller](presentation/VehicleHistoryController.ts) and its [real database/HTTP tests](presentation/VehicleHistoryController.e2e.spec.ts). Entry defaults off and requires an explicit local synthetic tester list as well as a current grant and elevated session. Staging and production are always refused.
