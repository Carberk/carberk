# Public Vehicle History information

The feature owns the local synthetic public offer and original fictional educational sample. Home and Listing detail use `HistoryEntry`; `app/vehicle-history/index.tsx` only passes optional Listing context. Availability defaults off and requires explicit development enablement with a loopback API. No authentication, customer request, provider, payment or marketplace Conversation is created here; #1177 owns connecting contact and request history.

`PublicOffer` owns sample presentation and recoverable file feedback. `saveFictionalSample` preserves the English document, verifies its local write, then opens the native export destination (iOS share sheet or Android document storage). Dismissal never claims an exported copy. Native storage/export is the test boundary; rendered component tests use the real feature and existing mobile harness.
