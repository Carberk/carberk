# Vehicle History

The feature owns the local synthetic public offer and original fictional educational sample. Home and Listing detail use `HistoryEntry`; `app/vehicle-history/index.tsx` only passes optional Listing context. Availability defaults off and requires explicit development enablement with a loopback API. Messages opens the private request reader. `PrivateReader` lists cursor-paginated enquiries and opens their GET-only detail; `session` and `src/api/vehicle-history/requests` resolve storage and fence each read/result to a viewer and stable Session ID, including refresh retries. Context never grants seller access. `useHistoryContact` owns one attempt per explicit contact/New request, genuine auth cancellation/once replay, retry-key retention and current caller/session/create-result fences. New enquiries enter the real reader and invalidate only that session’s history; reopening is GET only. No provider, payment or marketplace Conversation is created.

`PublicOffer` owns sample presentation and recoverable file feedback. `saveFictionalSample` preserves the English document, verifies its local write, then opens the native export destination (iOS share sheet or Android document storage). Dismissal never claims an exported copy. Native storage/export is the test boundary; rendered component tests use the real feature and existing mobile harness.
