# Dealer showroom prototype

Open [index.html](index.html) directly. Start with the 21-step full journey, then explore the seven focused flows. State stays in memory and resets on reload. Images and fonts are embedded. All people, cars and business details are fictional.

The phone-framed prototype covers personal/business switching, the existing listing wizard context, business inventory, shared enquiries and listing/showroom sharing. The [complete inspection workspace](../inspection-workspace-prototype/index.html) covers staff operations separately.

The full journey and seven focused flows were replayed in the browser before preservation here. The preserved copy changes only the staff-portal link to the durable workspace. Authentication, invitations, uploads, native/HTTPS links, crawlers, notifications, keyboard/screen-reader behavior and production integrations are not verified. English review copy only.

PRODUCT.md and DESIGN.md are original prototype briefs. The current PRDs and Chief of Staff handoff govern the proposed scope; prototype defaults do not settle open policies.
