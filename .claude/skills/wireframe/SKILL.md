# Deprecated wireframe route

This repository skill is retained as a compatibility pointer until the UI-artifact cleanup ticket removes it. Do not create or update a permanent wireframe artifact from this route.

For user-facing UI work, follow [ADR-0109](../../../docs/adr/0109-source-first-documentation-and-design-workflow.md) and apply the installed `ux-heuristics`, `design-everyday-things`, and `impeccable` skills to the affected interaction. Use a disposable prototype only when the issue needs visual evidence, then record the decision in the issue or PR.

Use the [glossary](../../../docs/domain/GLOSSARY.md) for domain terms. If an installed skill is unavailable, disclose that and use the documented fallback rubric rather than claiming it ran.
