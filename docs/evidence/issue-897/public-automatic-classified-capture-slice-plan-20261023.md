## Decision

Keep the first physical observation as the ownership anchor. Add a separately classified ownership component at that first forward `/vehicle` transaction, using the existing identity-rights vocabulary **before reading/copying ownership into a retained fact**. Do not postpone ownership capture to structured evidence append. Use strict searchable columns for the tuple and subject references, JSON only for the existing rights declaration, and later a database-owned irreversible visit-local bit. Preserve observationHash v1, raw/report pins and observation date/mileage. No backfill, retained-data recovery or general ownership ledger is needed.

The existing policy covers the restricted diagnostic identity/proof purpose and supplies a declaration/deletion model. The current endpoint does not implement that model for ownership. A valid rights-shaped object is not itself evidence of a right. No supplied source or specification names a source-specific basis/end covering a historical third-party seller or replaced membership subject at first raw collection. Wire a truthful declaration under existing rights; never infer that permission from consent to publish, physical access, current Listing access, an image's rights or synthetic runtime admission.

If root cannot supply such a declaration from existing rights, the one material question is: **Does the named source right permit retaining the Listing identity binding, historical seller and commissioner/member linkage from the first physical observation for restricted continuity comparison, including after replacement, until its explicitly authorized end and subject erasure?** Record the actual basis and permitted end if yes. Otherwise this component remains unavailable and automatic admission stays closed for those visits. This is a concrete collection-right gap, not a request to invent a retention policy or reapprove columns, bits, locks or worker plumbing. Synthetic tests can supply explicit synthetic declarations; they establish software behavior, not real collection rights.

No envelope means no ownership copy, while the ordinary authorized observation still succeeds. A malformed/expired envelope refuses without partial writes. Do not add current B publisher eligibility as an observation requirement. Incomplete source membership makes automatic facts unavailable; it does not erase an otherwise valid observation.

Once any earlier raw lacks a classified fact, later classification/reobservation cannot repair that visit for automatic continuity. An entirely new physical visit needs a new order. An existing upload declaration could be referenced only if it explicitly covered this separate component and all its subjects before raw capture; current stage rows prove no such coverage, so do not implement that shortcut.
