# Same-visit identity-method recording correction

The founder selected "Allow the supported recording correction" in the #897 release thread, after the concrete proposal to let an independent qualified reviewer correct a mistaken identity method using fresh supporting evidence. This records the decision received before 2026-10-23 UTC. It is approval evidence, not implementation or acceptance.

A mistaken manual identification may be corrected to VIN, or VIN to manual, only as a documented recording correction for the same physical visit. The independent qualified reviewer must have the existing required authority. Preserve the original report, inspection date, mileage and evidence. Retain explicit original/corrected values, rationale and supporting provenance under the existing restricted rights and lifecycle rules. Fresh evidence does not create a new physical visit or permit silent replacement of immutable pins. A genuinely later physical inspection requires a new order and its own observations.

This settles the method-transition classification left open in the [corrected mixed assembly](corrected-mixed-assembly-20261022.md). It does not settle broader automatic issuers, multiple-root eligibility, public publisher authority, collection rights, retention dates or real-center activation. ADR-0108 remains unchanged. A bounded contract/test assignment must specify how explicit same-visit correction records preserve the complete raw/evidence graph and authority, including refusals and immutable report-pin behavior, before source implementation. Material architecture changes still follow the repository decision workflow. No HTTP acceptance for the newly approved method transition is claimed.

The separate [limited staff handoff approval](staff-foundation-disposition-20261022.md#founder-approval-recorded-2026-10-23-utc) is recorded with prerequisite #923. Both decisions remove repeated founder questions; they do not complete #914/#915 or the selected release scope.
